# taken-my 1.0.1

- 回到最初版本的短章阅读方式，用更轻巧的中英文文案讲述实际得到的设备、语言、时间与页面线索。
- 只展示成功取得的信息；失败、未授权、能力诊断与空项不进入页面，有效的 `0` 和 `false` 继续保留。
- 将原始查询语句改为普通语言；补充信息清单保留搜索，不显示 API、端口、采集来源或状态标签。
- 保留用户主动触发的图形与候选字体查看，移除面向访客的权限诊断入口。没有新增权限请求、云端服务或上传。
- 本地副本改为 `schemaVersion: 2`，只保存成功显示的信息名称与值（当前语言），不含内部字段、来源、错误或权限状态。
- 增补成功结果筛选、空章节、零值、双语展示、异步刷新、导出一致性和浏览器回归测试。

此版本提供静态网站发行包；发布包不等于部署到服务器。构建与使用见[项目说明](../../README.md)。
