# taken-my 1.0.0

## 更新

- 首次提供可以独立部署的静态网站发行包。
- 浏览器信息检查、结果筛选与详情展示使用当前已通过测试的实现。
- 页面字体随站点发布，保留各字体许可证和来源说明。
- 发行包记录源码提交与每个站点文件的 SHA-256，提供统一附件校验和。

## 下载与部署

提供 `taken-my-1.0.0-static.tar.gz`、`taken-my-1.0.0-static.zip`、`release-identity.json` 与 `SHA256SUMS`。两个归档包含相同的静态站点文件，解压后可以由静态 Web 服务器托管。

运行和构建步骤见[项目说明](../../README.md)。
